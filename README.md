### Шаг 5. Broken

Метод `Broken` приводит к `StackOverflowException`, потому что метод не имеет условие выхода, что приводит к бесконечной рекурсии. Стек не очищается, так как ни один из предыдущих вызовов не завершается. 
Для того, чтобы выполнить код внутри блока `catch`, среде выполнения нужно выделить новый фрейм вызова для обработчика ошибок, но свободного места на стеке нет совсем.


## Часть 4. Самостоятельная рекурсия

### Задача C. Найди ошибку в рекурсии
1. В коде ниже в рекурсивном вызове параметр `n` не изменяется, из-за этого метод не достигнет базового случая
```csharp
int Sum(int n) {
    if (n == 0)
        return 0;

    return Sum(n);
}
```

2. В коде ниже шаг рекурсии `n + 1` увеличивает `n`. Если изначальное `n > 0`, оно будет расти и никогда не достигнет `0`, что приведет к переполнению стека. (Для отрицательных `n` рекурсия бы завершилась)
```csharp
int Sum(int n) {
    if (n == 0)
        return 0;

    return n + Sum(n + 1);
}
```
